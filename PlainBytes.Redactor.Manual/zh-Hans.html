1. 产品定位与安全原则

PlainBytes Redactor 面向法律、金融、审计及高隐私场景，在本机离线完成 PDF 的检测、复核与物理脱敏。

  • 离线安全：规则匹配、可选本地 AI 推理与 PDF 处理均在当前电脑执行，应用自身不发起网络上传。
  • 物理脱敏：敏感内容从 PDF 内容流中移除，而非仅视觉遮盖。
  • 设备端 AI：可选 ONNX 模型在本地运行；不向云端传输文档内容。
  • 元数据：导出时可配合清理文档属性与隐藏数据，降低通过文件属性泄露身份的风险（批量任务中亦有对应选项）。
打开网页、应用商店或邮件链接时，由系统默认浏览器/客户端处理；该行为与应用内处理 PDF 时的离线原则相互独立。

2. 版本与可用功能

应用可能以试用、专业版（Pro）或试用结束等状态运行。

  • 导出已脱敏、批量处理、识别/重新识别等是否可用以软件内实际状态为准。
  • 试用结束后可通过 Microsoft Store 购买 Pro（以商店与软件内说明为准）。

3. 主界面与工具栏

  • 打开文件：本地 PDF 或常见图片格式。
  • 关闭文档。
  • 上一页 / 下一页：预览翻页。
  • 本地规则：规则中心（区域、场景、规则开关与自定义规则）。
  • 批量：批量脱敏控制台。
  • 导出已脱敏：导出 PDF。
  • 更多选项：语言、使用帮助、反馈与支持、检查更新、关于等。

布局为左侧预览、右侧审计侧栏；状态栏显示就绪与 AI 引擎状态等。

4. 推荐工作流程（单文件）

  1. 拖入或打开文件加载 PDF/图片。
  2. 在本地规则中心设置区域与业务场景，在单页中点击开始识别（规则 + 可选本地 AI）。策略变更后可再次识别。
  3. 在审计侧栏复核列表；仅已确认项参与导出。预览中黄色区域可点击切换确认。
  4. 必要时手动框选补充区域。
  5. 导出已脱敏并查看完成摘要。
  6. 同质文档多时可另存为通用模板并配合批量处理。

5. 本地规则中心

5.1 区域与场景

选择区域与业务场景（通用、金融、医疗、法律政务等）。规则来自本地数据（如 LocalPatterns.json），可完全离线使用。

5.2 分类与开关

按页签浏览身份、金融、地址、联系方式、技术/其他、自定义等，单独启用或关闭规则。

5.3 自定义规则

名称 + 匹配模式；可为纯文本子串（不区分大小写）或 .NET 正则。删除前有确认；数量可能有上限。

5.4 恢复默认

清除本地覆盖，还原内置预设（需确认）。

6. 审计侧栏与确认逻辑

  • 按类别、风险等级筛选。
  • 对聚合项确认/取消确认；支持批量切换当前筛选下可见项（见界面提示）。
  • 可从列表移除条目。
  • 无自动结果时可用手动框选。
只有已确认区域会在导出时物理删除，导出前请务必复核。

7. 手动框选脱敏

在预览上拖拽矩形添加手动标记；可在选区外观中调整描边与填充颜色。

8. 导出已脱敏 PDF

  • 至少确认一项区域后方可导出。
  • 完成对话框含物理移除数量、元数据清理及可选文本校验摘要；有警告时请人工复查导出文件。
  • 栅格类文档与矢量 PDF 路径可能不同，以提示为准。

9. 模板与批量脱敏

9.1 另存为通用模板

将当前已确认区域保存为命名模板，供批量任务选择。

9.2 批量控制台

  • 拖入文件夹或多份 PDF，或浏览添加队列。
  • 选择输出文件夹与脱敏模板（可选用当前文档标记同步）。
  • 可选清除文件属性与隐藏数据（作者、时间戳、XMP 等）。
  • 查看完成统计、校验摘要与审计报告（若生成失败会有提示）。
「应用到多个文件」等对文档类型与版本状态有要求，以按钮是否可用为准。
