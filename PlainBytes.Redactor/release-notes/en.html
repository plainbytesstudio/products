release notes

Version 1.2.0

Added redaction scheme management, image redaction, and batch processing, with comprehensive improvements to the preview window experience.

New features

Notable additions in this release.

  • Redaction Scheme Management

    Create, import, export, and delete redaction schemes. Importing a scheme with a duplicate name overwrites the existing one.

  • Apply Scheme to Single File

    Apply a saved redaction scheme directly to the currently open file.

  • Batch Apply Scheme

    Apply a redaction scheme across multiple files with identical structure.

  • Paste from Clipboard

    Paste an image from the clipboard for redaction (Ctrl+V). Available only when the clipboard contains image content — otherwise the "Paste from Clipboard" button remains disabled.

  • Copy Redaction Result to Clipboard

    Copy the redacted image result directly to the clipboard (Ctrl+C). Available in image redaction mode only — otherwise the "Copy to Clipboard" button remains disabled.

  • Image Export Formats

    Redacted images can be exported as PNG or JPG.

  • Preview Window Zoom and Page Navigation

    The preview window now supports zoom controls and direct page number navigation.

  • Mosaic Redaction Style

    A mosaic style option has been added to redaction styles, available in image redaction mode only.

Improvements & fixes

UX polish and stability fixes.

  • When opening or pasting content, the maximum zoom level is capped at 100%. If the original size exceeds 80% of the available preview width, the zoom level adjusts automatically to fit.

  • Zoom level is preserved when the window is resized.

  • The detection policy panel and redaction appearance panel have been merged into a single tabbed panel, simplifying the sidebar layout.

  • The preview window close button has been moved from the toolbar to the top-right corner of the preview window.

  • Improved image rendering clarity.
