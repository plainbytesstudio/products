Release notes

Version 1.0.0

Highlights

  • Physical redaction — sensitive text is removed from PDF content streams, not just covered.
  • 100% offline — rule scanning, optional local AI, and export run on your PC.
  • Audit workflow — review, confirm, manually add regions, then export.
  • Batch apply — reuse confirmed geometry across similar documents.
  • Multi-region rules — built-in patterns for CN, JP, US, EU, RU, and more.

Improvements & fixes

  • More accurate auto-detection boxes for Japanese label-and-value fields (phone, My Number, URLs).
  • Preview scrollbar corner styling when both axes scroll.
  • Scheme coordinates use absolute page geometry for consistent template placement.
  • Stability fixes for rescan and UI thread updates during recognition.
