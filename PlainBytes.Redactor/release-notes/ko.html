릴리스 노트

버전 1.2.1

redaction 방안 관리, 이미지 redaction 및 일괄 처리를 추가하고, 미리보기 창 환경을 전반적으로 개선했습니다.

새 기능

이번 릴리스의 주요 추가 사항.

  • 편집 스킴 관리

    편집 스킴을 생성, 가져오기, 내보내기 및 삭제할 수 있습니다. 이름이 중복된 스킴을 가져올 경우 기존 스킴이 덮어씌워집니다.

  • 단일 파일에 스킴 적용

    저장된 편집 스킴을 현재 열려 있는 파일에 직접 적용할 수 있습니다.

  • 스킴 일괄 적용

    구조가 동일한 여러 파일에 편집 스킴을 일괄 적용할 수 있습니다.

  • 클립보드에서 붙여넣기

    클립보드의 이미지를 붙여넣어 편집할 수 있습니다(Ctrl+V). 클립보드에 이미지 콘텐츠가 있을 때만 사용할 수 있으며, 그렇지 않으면 "클립보드에서 붙여넣기" 버튼이 비활성화된 상태로 유지됩니다.

  • 편집 결과를 클립보드로 복사

    편집이 적용된 이미지를 클립보드에 직접 복사할 수 있습니다(Ctrl+C). 이미지 편집 모드에서만 사용할 수 있으며, 그렇지 않으면 "클립보드로 복사" 버튼이 비활성화된 상태로 유지됩니다.

  • 이미지 내보내기 형식

    편집된 이미지를 PNG 또는 JPG 형식으로 내보낼 수 있습니다.

  • 미리보기 창의 확대/축소 및 페이지 이동

    미리보기 창에서 확대/축소 조절 및 페이지 번호를 통한 직접 이동을 지원합니다.

  • 모자이크 편집 스타일

    편집 스타일에 모자이크 옵션이 추가되었으며, 이미지 편집 모드에서만 사용할 수 있습니다.

개선 및 수정

UX 개선 및 안정성 수정.

  • 콘텐츠를 열거나 붙여넣을 때 최대 확대 비율은 100%로 제한됩니다. 원본 크기가 미리보기 창 사용 가능 너비（80%）를 초과하면 자동으로 비율을 조정하여 표시합니다.

  • 창 크기가 변경되어도 현재 확대 비율을 유지합니다.

  • 감지 정책 패널과 선택 영역 외관 패널이 탭 형식으로 통합되어 사이드바 구조가 간소화되었습니다.

  • 미리보기 창의 닫기 버튼이 도구 모음에서 미리보기 창 오른쪽 상단으로 이동되었습니다.

  • 이미지 표시 선명도가 개선되었습니다.
