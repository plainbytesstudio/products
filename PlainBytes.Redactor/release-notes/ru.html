примечания к выпуску

Версия 1.2.0

Добавлено управление схемами скрытия данных, скрытие данных на изображениях и пакетная обработка, а также значительно улучшена работа с окном предпросмотра.

Новые возможности

Основные дополнения в этом выпуске.

  • Управление схемами скрытия данных

    создавайте, импортируйте, экспортируйте и удаляйте схемы скрытия данных. При импорте схемы с уже существующим именем текущая схема будет перезаписана.

  • Применение схемы к одному файлу

    применяйте сохранённую схему скрытия данных непосредственно к открытому в данный момент файлу.

  • Пакетное применение схемы

    применяйте схему скрытия данных сразу к нескольким файлам с одинаковой структурой.

  • Вставка из буфера обмена

    вставляйте изображение из буфера обмена для скрытия данных (Ctrl+V). Функция доступна только при наличии изображения в буфере обмена — в противном случае кнопка «Вставить из буфера обмена» остаётся неактивной.

  • Копирование результата скрытия данных в буфер обмена

    копируйте изображение с скрытыми данными прямо в буфер обмена (Ctrl+C). Доступно только в режиме скрытия данных на изображениях — в противном случае кнопка «Копировать в буфер обмена» остаётся неактивной.

  • Форматы экспорта изображений

    изображения со скрытыми данными теперь можно экспортировать в форматах PNG или JPG.

  • Масштабирование и переход по страницам в окне предпросмотра

    в окне предпросмотра теперь доступны элементы управления масштабом и переход к странице по её номеру.

  • Стиль скрытия данных «мозаика»

    в стилях скрытия данных появилась опция «мозаика», доступная только в режиме скрытия данных на изображениях.

Улучшения и исправления

Доработка UX и исправления стабильности.

  • Синхронизация предпросмотра и списка аудита: выбор записи точнее позиционирует предпросмотр.

  • Более точные рамки для японских полей «метка: значение» (телефон, My Number, URL).

  • Стиль угла предпросмотра при одновременном появлении обеих полос прокрутки.

  • Координаты схемы используют абсолютную геометрию страницы для стабильного размещения шаблонов.
